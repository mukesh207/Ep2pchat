# ADR-002: WebAuthn/FIDO2 for Passwordless Authentication

**Status:** Accepted  
**Date:** 2026-03-15  
**Authors:** Trustline Engineering

## Context

Passwords are the single weakest link in authentication — susceptible to phishing, credential stuffing, and database breaches. Enterprise messaging platforms handling sensitive communications need authentication that cannot be phished or replayed.

## Decision

Trustline uses **WebAuthn/FIDO2 (Passkeys)** as the sole authentication mechanism:

1. **Backend:** `webauthn-rs` v0.5 handles challenge generation, credential registration, and assertion verification.
2. **Frontend:** `@simplewebauthn/browser` orchestrates the browser-side credential ceremony.
3. **Session management:** Short-lived JWTs (24-hour expiry) issued after successful WebAuthn assertion.
4. **Device binding:** Each passkey registration creates a device entry with its own `device_id` and cryptographic identity (X3DH keys).
5. **Onboarding flow:** Admin approves corporate email → User registers device via biometrics/security key → Device generates X25519 identity keys.

## Consequences

- **Positive:** Zero phishing risk — private keys are hardware-bound and never leave the Secure Enclave.
- **Positive:** No password database to breach.
- **Positive:** Multi-device support via multiple passkey registrations.
- **Negative:** Requires a platform authenticator (Touch ID, Windows Hello, security key) — older devices without biometrics need a hardware key.
- **Negative:** Account recovery is limited to admin-initiated device re-approval.
